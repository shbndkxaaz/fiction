⑥ 说明 第一次用跟着这四步走


            

              
四步跑通

              

                1. ① 书库 → 选 TXT 导入（自动切段、识别章节）

                2. ② 清洗 → 填 API 地址 / Key / 模型 → 点「开始清洗」，等它逐段跑完

                3. ③ 注入 → 点「预览本轮注入」看一眼 → 回聊天正常聊，知识会自动进提示词

                4. ④ 每演完一段原著就点「推进一个节点」；⑤ 想自己写就点「AI 续写」
              

            


            

              
它怎么工作（一句话）

              

                你的 TXT 被清洗成「剧情节点 + 角色设定 + 世界设定 + 总结 + 伏笔」，

                聊天时按 token 预算裁好后并进**第一条 system 提示词**（不新增 system 消息，Claude / Gemini 才不会报错），

                续写时用的是同一份内容 —— 所以演的和写的不会互相打脸。
              

            


            

              
三个进阶开关（写不下去时最喜欢用的）

              

                · ③ 未来大纲滑窗：0 = 完全不剧透、自由发挥；1~2 = 平衡（推荐）；3~5 = 强约束，贴着原著大事件走

                · ⑤ 💡 启发后续大纲：按当前剧情给 3 条走向（主线 / 感情 / 张力），可「采纳为节点」或「带入续写要求」

                · ⑤ 💋 幕间模式：勾上后不跳时间、不推进节点，只把当前场景写细；下面的标签点一下就拼进定向要求
              

            


            

              
省钱 & 防坑

              

                · 清洗是唯一花钱的大头，按段计费；分段调大 = 省钱但抽得粗

                · 取消顶部「启用注入」= 完全不注入、不发任何请求（续写按钮仍可用）

                · 书存在 localStorage：清浏览器缓存会丢，记得在 ① 导出 JSON 备份

                · 聊天注入只影响提示词，不改你的聊天记录；草稿也只存在书里
